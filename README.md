# Smart Traffic Management System

## Overview

This project was developed as part of a university engineering project using Arduino. The system simulates an intelligent traffic management system with vehicle detection and pedestrian crossing functionality.

# Features

- Six-stage traffic light control
- Pedestrian push button
- Ultrasonic vehicle detection
- Automatic traffic sequencing
- Safety-focused traffic control logic

# Hardware

- Arduino Uno
- Ultrasonic Sensors (HC-SR04)
- LEDs
- Push Button
- Breadboard and jumper wires

# Software

- python
